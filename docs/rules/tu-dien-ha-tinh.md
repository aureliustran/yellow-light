# Đèn vàng – từ điển giọng Hà Tĩnh (`[[ht: gốc || chuẩn]]`)

Nov 1, 2026 · @aureliustran. Nguồn: tác giả bổ sung 01/11 `[stated]`; các mục ở §2 rút từ chữ đã có trên trang (ch.2–5, interlude). Khi viết `[[ht: …]]`, ô thứ hai giữ nguyên chữ phổ thông của bản gốc.

| Hà Tĩnh | Phổ thông | Ghi chú |
| --- | --- | --- |
| nhởi | chơi | |
| mần | làm | đã dùng: "mần chi mà ăn" |
| chộ | thấy | |
| dừ thì | giờ thì | |
| đê | thôi (trong "đi thôi") | cuối câu rủ: "Đi đê." |
| tề | mà (chỉ trong biểu cảm, cuối câu) | "Đừng tề", "Không run thật tề". **Không** dùng cho "mà" nối trong cấu trúc câu ("làm gì mà ăn", "câu gì mà mặt…"): giữ "mà" (chốt 01/11) |
| nỏ | không | |
| cấy | cái | |
| năng | sao, thế nào | thay "răng" (chốt 01/11); đã đổi trên trang |

## 2. Từ đã dùng trên trang

| Hà Tĩnh | Phổ thông |
| --- | --- |
| tau / mi | tao / mày |
| rứa | thế |
| chi | gì |
| mô | đâu, nào |
| ni | này |
| tê | kìa |
| chơ | chứ | thay "chớ" (chốt 01/11) |
| vô | vào |

## 3. Luật dùng

- **Bố, mẹ không đổi sang bọ, mạ** (chốt 01/11). Toàn bộ "bọ", "mạ" đã có trên trang được đưa về "bố", "mẹ" (01/11).
- Thuyên và Vũ nói với nhau bằng giọng Hà Tĩnh (ch.2, ch.5); Thuyên với người Hà Nội dùng giọng Hà Nội (bộ dịch).
- Chữ tục và viết tắt (đm, vcl, cc) giữ nguyên, không đổi.
- Câu giống hệt giữa hai giọng thì để nguyên, không bọc `[[ht]]`.
- Tin nhắn chat giữ lối viết tắt: "mi" thay "m", "tau" viết tắt "t".
